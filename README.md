<h2>About this project</h2>
<hr>
<p>This is a hardware project that I'm doing for a Hack Club event, more specifically "Half Life." This is my first iteration, and I only have left the firmware of the project. will be doing that today once I finish this repo.</p>

<br>

<h2>What is this?</h2>
<hr>
<p>As its name says, it is a MIDI keypad. I'm using a Xiao Seed ESP32-S3 Zero for the MCU. It has 6 pads for input, 3 LEDs, 3 bottoms, an EC11 rotary encoder with a switch, and a 0.98 128 x 32 OLED..</p>
